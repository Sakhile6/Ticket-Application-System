## Project Description
A C# Windows Forms application that calculates ticket prices
based on passenger details, travel category, and distance.

## Business Rules
- Category One: R20 per km
- Category Two: R35 per km
- Category Three: R50 per km
- Age under 12: FREE ticket
- Female passenger: 50% discount
